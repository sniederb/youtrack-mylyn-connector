# Contributing to the YouTrack Mylyn Connector

Thank you for your interest in improving this plugin! Because this is a lightweight utility 
designed for specific, core issue-tracking workflows, contributions must align with the project's 
minimalist scope.

## How You Can Help

* **Bug Fixes:** If you find a bug or a compatibility issue with a newer version of Eclipse or YouTrack, pull requests (PRs) are highly welcome.
* **Eclipse/YouTrack Lifecycle Updates:** Updates required to keep the plugin working alongside modern API changes or token authentication standards are encouraged.

## Guidelines for Pull Requests

1. **Keep it focused:** Fix one specific bug or add one missing critical mapping per PR.
2. **Scope match:** Please avoid submitting large feature requests or massive architectural overhauls, as the project intends to remain a simple drop-in tool.
3. **Testing:** If possible, briefly describe how you verified your fix in your PR description.

*Note: As this project is maintained on an as-needed basis, PR reviews may take some time. Your patience is greatly appreciated!*
