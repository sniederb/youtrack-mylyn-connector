Very basic Mylyn connector to a YouTrack repository.

The implementation is based on using a YouTrack permanent token (Users > Account Security > Tokens), which needs to be set as password.

Based on [Mylyn Bugzilla UI plugin](https://github.com/eclipse-mylyn/org.eclipse.mylyn.tasks/tree/master/org.eclipse.mylyn.bugzilla.ui) and 
[Mylyn Bugzilla core plugin](https://github.com/eclipse-mylyn/org.eclipse.mylyn.tasks/tree/master/org.eclipse.mylyn.bugzilla.core)
