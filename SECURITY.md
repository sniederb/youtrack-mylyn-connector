# Security Policy

## Supported Versions

Security updates are handled on a best-effort basis for the latest release available on the GitHub Releases page. 

## Reporting a Vulnerability

Because this plugin handles sensitive data (such as your YouTrack permanent authentication tokens), security is taken seriously. 

If you discover a potential security vulnerability within this connector:
1. Do **not** open a public GitHub Issue.
2. Instead, please report it responsibly by opening a draft Security Advisory directly through this repository's **Security** tab, or contact the maintainer directly via GitHub profile details.
3. Please provide a brief description of the issue and steps to reproduce it.

Thank you for helping keep this project secure for the community!
